# Interactive 3D Globe

A full-viewport Three.js globe with:

- Smooth auto-rotation that pauses during drag interaction.
- Drag-to-spin and wheel/pinch camera controls.
- Glowing, pulsing location markers.
- Click-to-focus camera transitions for featured locations.
- Soft ambient and directional lighting.
- Subtle atmospheric halo and star field.
- Responsive featured-location panel.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The globe uses the Earth texture from the Three.js examples CDN at runtime.
